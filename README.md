# 🚢 Titanic Dataset Analysis, Visualization & Machine Learning

## 📌 Project Overview

This project explores the Titanic dataset through data analysis, statistical calculations, visualization, and machine learning using Python. It combines Exploratory Data Analysis (EDA) with TensorFlow to investigate passenger survival patterns and explore how machine learning can be applied to classification problems.

The project focuses on transforming raw passenger data into meaningful insights through statistical analysis, different visualizations, and neural network modeling.

## 🎯 Objectives

- Clean and preprocess the dataset.
- Perform statistical calculations and exploratory data analysis.
- Analyze passenger survival based on age, sex, passenger class, and other available features.
- Create different charts to identify patterns and relationships.
- Apply TensorFlow to develop and train a neural network for classification.
- Evaluate model performance using appropriate evaluation metrics.
- Understand the practical workflow of a data science and machine learning project.

## 🛠️ Technologies & Libraries

- **Python** — Core programming language.
- **Pandas** — Data manipulation and analysis.
- **NumPy** — Numerical computations.
- **Matplotlib** — Data visualization.
- **Seaborn** — Statistical charts and visual exploration.
- **TensorFlow / Keras** — Neural network development and training.
- **Jupyter Notebook** — Interactive development and experimentation.

## 📊 Data Analysis & Visualization

The project explores the dataset using statistical calculations and graphical representations, such as:

- Bar charts and count plots to compare passenger groups.
- Histograms to examine age and fare distributions.
- Pie charts to visualize proportions.
- Box plots to investigate distributions and potential outliers.
- Heatmaps to examine correlations between numerical features.
- Survival rate calculations to compare passenger categories.

## 🤖 Machine Learning with TensorFlow

TensorFlow was used as part of the machine learning workflow to explore neural networks and classification.

The workflow includes:

1. Preparing and preprocessing the dataset.
2. Selecting relevant input features and the target variable.
3. Converting the data into a suitable format for modeling.
4. Building a neural network using TensorFlow/Keras.
5. Training the model on the prepared data.
6. Evaluating its performance using appropriate metrics.

The classification task focuses on predicting whether a Titanic passenger survived based on available passenger information.

## 🔍 Key Questions

- What proportion of passengers survived?
- How did survival rates differ by sex and passenger class?
- What patterns can be identified in passenger age and fare?
- Which features may be useful for predicting survival?
- How can a TensorFlow neural network approach this classification problem?

## 📚 Dataset

The project uses the Titanic passenger dataset, which commonly includes features such as PassengerId,	Survived,	Pclass,	Name,	Sex,	Age,	SibSp,	Parch,	Ticket,	Fare, Cabin,	Embarked and survival status.

The target variable is typically `Survived`:

- `0` — Did not survive.
- `1` — Survived.
